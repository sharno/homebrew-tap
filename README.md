# sharno/homebrew-tap

Homebrew formulae for [sharno](https://github.com/sharno)'s tools.

```bash
brew install sharno/tap/hunker
```

| Formula                     | Description                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------- |
| [hunker](Formula/hunker.rb) | [Local GitHub pull-request and Git diff reviewer](https://github.com/sharno/hunker) |

Each project's release workflow updates its formula here.
